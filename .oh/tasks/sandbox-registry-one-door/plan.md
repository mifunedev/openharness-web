## Context

`cd ~/.openharness && oh sandbox && oh shell`.

`main` (`scripts/oh-source.mjs`, `OH_SCRIPTS_REF || "main"`); `install.sh` is a CDN 302 to `main`.

(#37, #23 open). PRs target `main`, squash-merged, recent titles `FROM <branch> TO main (#N)`.

## Mirror procedure (throwaway script, run once)

`<scratchpad>/mirror-docs.mjs` (Node ESM, no deps; not committed — mention in the PR as a candidate
for `scripts/`). Constants: `HARNESS=.worktrees/task/950-sandbox-registry/docs`,
`SITE=projects/mifunedev/openharness-web/docs`, `GH=https://github.com/mifunedev/openharness/blob/main`,
`SITE_ONLY=[docker-deployment.md, model-selection.md, integrations/pi-autoresearch.md]`,
`DELETE=[harnesses/deepagents.md]`, a `PAGES` map (rel path → frontmatter to merge: `id`, `slug`,
`sidebar_position`, `title`; title falls back to the harness `title:` then the H1 with backticks
stripped), and the `FIXUPS` map above. Per page: read → split optional frontmatter → merge keys in the
order `id, slug, sidebar_position, title` → rewrite links → apply FIXUPS (throw unless exactly one
match) → write. Print every rewrite as `page:line old -> new`.

Link rules for every `](target)`: (1) `http(s)://`, `mailto:`, bare `#a` unchanged; (2) site route
`/docs/<x>` kept when `docs/<x>.md` will exist on the site, else `${GH}/docs/<x>.md`; `/blog/...`
unchanged; (3) relative `.md` target resolved against the page dir to a repo-relative path `P`: kept
relative when `P` is `docs/<rel>` and `<rel>` will exist on the site, else `${GH}/${P}` (+anchor);
(4) any other relative target (`../.devcontainer/Dockerfile`, `../.env.example`, `../CONTRIBUTING.md`)
→ `${GH}/${P}`; (5) "will exist" = `keys(PAGES) ∪ SITE_ONLY − DELETE`. Expected unmirrored targets:
security-considerations, integrations/sshd, integrations/herdr, glossary, rfcs/*, harness-manifest,
repair-operator-registry, `.oh/README.md`, `.oh/skills/**`, `.devcontainer/*`, `.env.example`,
